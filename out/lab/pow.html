PROTOCOL MODULE / PoW

Proof of Work

How can open networks agree without knowing or trusting every participant?

Miners compete to find a nonce that produces a valid block hash. The first valid block is broadcast, independently checked and extended by the network.

TRANSACTION → BLOCK

Follow the consensus process

05 observable events
01

Create and sign

A wallet creates a transaction and signs it with the sender’s private key.

02

Verify and queue

Nodes verify the signature, balance and rules, then place the transaction in the mempool.

03

Build and mine

Miners select transactions, form a candidate block and repeatedly change the nonce.

04

Broadcast and check

The winning miner broadcasts the block. Other nodes verify its hash and every transaction.

05

Extend the chain

Nodes accept the valid chain. Each later block makes reversal more difficult.
